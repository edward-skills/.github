提供已有内容、品牌资料与素材，按任务选一个 Skill，安装到具备相应工具的 Agent 后即可开始。

## 按任务选择

| 你要做什么 | Skill | 主要输入 |
| --- | --- | --- |
| 品牌官网、B2B 询盘站、SaaS 官网 | [Website Design Build](https://github.com/edward-skills/website-design-build) | 品牌介绍、网站内容、产品图片/截图与套餐资料 |
| 品牌营销内容与素材文档 | [Brand Marketing Pack](https://github.com/edward-skills/aident-brand-marketing-pack) | 已有品牌资料或新品牌想法 |
| 海报、Banner 与分镜素材 | [Brand Visual Production](https://github.com/edward-skills/aident-brand-visual-production) | 已确认的文案、Logo 与视觉 brief |
| 角色或数字员工 IP 系统 | [Avatar IP System](https://github.com/edward-skills/produce-avatar-ip-system) | 角色想法、参考和应用场景 |
| 演示文稿与 Motion Slides | [PPT Skill](https://github.com/edward-skills/aident-ppt-skill) | 受众、目标、内容框架和可选品牌素材 |
| 搜索增长调研与优化 | [SEO Growth Agency](https://github.com/edward-skills/aident-seo-growth-agency) | 品牌官网/介绍、目标市场与竞品网址 |

一个 Organization 统一展示，每个 Skill 保留独立仓库、版本、Issues、素材和检查。只安装需要的能力，不强制串联完整工具箱。内容齐全时可以直接搭建网站。

## 开始使用

```bash
npx skills add edward-skills/website-design-build --skill website-design-build
```

```text
使用 website-design-build。附件是品牌介绍、产品截图与套餐资料。
请做首页、价格页和登录页，给我可打开的网页预览。
其他设计与实现选择由你完成，不编造缺失的业务事实。
```

按安装器提示选择宿主。手动安装需要复制完整包，保留引用素材。能否实际执行取决于 Agent 的工具和账户权限；Muse AI、Grok Bot 的说明及验证边界见各仓库。
