## Choose a Skill

| Your task | Skill | What to bring |
| --- | --- | --- |
| Design and build a brand, B2B or SaaS website | [Website Design Build](https://github.com/edward-skills/website-design-build) | Introduction, website content, photos/screenshots and any plan details |
| Create a complete brand marketing pack | [Brand Marketing Pack](https://github.com/edward-skills/aident-brand-marketing-pack) | Existing brand sources or a new brand idea |

| Research and improve search growth | [SEO Growth Agency](https://github.com/edward-skills/aident-seo-growth-agency) | Website/brand brief, target market and competitor URLs |

Each Skill remains an independent repository with its own versions, issues, assets and checks. Install only what you need. You can build a website directly when your content is ready; the other Skills are optional companions.

## Start with one task

For example:

```bash
npx skills add edward-skills/website-design-build --skill website-design-build
```

```text
Use website-design-build. Attached are our brand introduction, product screenshots
and plan details. Build an English homepage, pricing page and sign-in page with a
preview I can open. Make routine design choices yourself; do not invent facts.
```

Select your host in the installer. Copy the complete Skill package, including referenced materials, when installing manually. Host tools and account access determine what can actually run. See each repository for requirements and the limits of its compatibility checks, including Muse AI and Grok Bot guidance.
